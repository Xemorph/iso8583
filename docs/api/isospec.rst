ISOSpec — YAML-Loader
=====================

Der ``SpecDecoder`` lädt Feldspezifikationen aus YAML-Dateien
und erzeugt daraus einen fertigen Parser. Die Struktur der
YAML-Datei ist in :doc:`../internals/yaml_format` beschrieben.
